## Excluded upstream file

`full-game-answer-pool.txt` (the six-turn simulation answer pool, 2,354 words) is part of the canonical release but is **not** CC BY: it remains under its upstream source terms. It is intentionally omitted from this package. `data/manifest.json` is reproduced byte-for-byte and therefore still lists the file and its checksum. If you need it, download it from the canonical release and respect its upstream terms.

No file in this package maps dates to answer words.
